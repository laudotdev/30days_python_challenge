# 30 Days Python Challenge

A personal coding challenge documenting my journey of learning Python and backend web development through daily projects.

The goal is to strengthen my programming fundamentals, understand backend development, and gain practical experience by building projects independently.

## Learning Objectives

- Strengthen Python fundamentals.
- Understand Flask and backend architecture.
- Learn how frontend and backend communicate.
- Work with HTTP methods, requests, and responses.
- Practice API development and backend validation.
- Improve problem-solving and debugging skills.

## Learning Approach

I believe in learning by building, experimenting, debugging, and understanding the logic behind every line of code rather than simply memorizing solutions.

Each project is an opportunity to learn something new and improve my development skills.
